# Hydraulic Jump Calculator

Бесплатный прототип инженерного расчёта гидравлического прыжка.

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Откройте адрес, который покажет Streamlit (обычно `http://localhost:8501`).

## Модель

Расчёт сопряжённой глубины выполняется по равенству функции количества движения. Поддерживаются прямоугольное и трапецеидальное сечения. Длина прыжка и выбор типа бассейна являются предварительными инженерными оценками и должны быть проверены по применяемому стандарту сооружения.

## Публикация бесплатно

Репозиторий можно подключить к Streamlit Community Cloud и получить ссылку `streamlit.app`. Для служебных или конфиденциальных данных используйте локальный запуск или внутренний сервер.
