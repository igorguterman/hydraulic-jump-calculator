# Гидравлический прыжок — версия 1.0.0

Работающее приложение: https://hydraulic-jump-igorguterman.streamlit.app/

## Назначение

Расчётный инструмент для установившегося свободного прыжка в открытом призматическом прямоугольном/трапецеидальном русле и проверка размещения в горизонтальном бассейне без гасителей. Это законченный модуль в указанных границах, а не универсальная система проектирования гидроузла.

## Возможности

- Сопряжённые глубины по импульсу, критическая глубина, скорости, Fr, энергия, мощность диссипации при плотности 1000 кг/м³, невязка импульса.
- Длина прямоугольного прыжка по FHWA HEC-14 (7.25); произвольный множитель удалён. Для трапеции длина не подставляется автоматически.
- Профили GVF с Маннингом от входа и нижнего бьефа; поиск точки равных импульсов.
- Проверка B−x−L: запас длины для свободного прыжка. Для внешней длины обязательно указать обоснование.
- Остановка у критического состояния; отсутствие, неопределённость или множественность решений выводятся явно.
- Контроль координаты повторным решением с более строгой точностью.
- Расчёт нормальной глубины отдельного подходящего участка.
- Сценарии с отдельными Q, yвх и yнб; CSV.
- Сохранение/загрузка проекта JSON, воспроизводимый ID исходных данных.
- Автономный HTML-отчёт с формулами, источниками и графиком ветвей; печать PDF через браузер.

## Применение

1. Все значения вводятся в SI. Ширина трапеции — ширина дна, z — горизонталь/вертикаль.
2. yвх задаётся у входа в горизонтальный бассейн; yнб — на выходе от того же дна. B — расстояние между этими сечениями.
3. На вкладке «Прыжок» результат относится к заданной входной глубине. На вкладке «Бассейн» параметры относятся к найденному месту прыжка и могут отличаться из-за трения на подходе.
4. Составной профиль — точечный разрыв. Его вертикальная линия не является формой реального валика.
5. При отсутствии применимой формулы длины можно загрузить обоснованную длину из модели/другой методики; без неё проверка размещения не выдаёт положительного заключения.
6. Сохраните проект JSON. Данные сессии не являются постоянным хранилищем.

## Ограничения

Горизонтальное дно в зоне прыжка; гидростатика в удалённых сечениях; α=β=1; трение внутри скачка не учитывается. Маннинг применяется только на плавных ветвях. Волнистые переходы требуют отдельного анализа. Расчёт не включает затопленный и нестационарный прыжок, наклонное днище, меняющуюся ширину, пороги/блоки, размыв, нагрузки/прочность, кавитацию, воздухововлечение, высоту стенок. Подсказки USBR/SAF удалены: эти конструкции здесь не рассчитаны.

Диапазон Fr=1.7–17 для использования длины (7.25) — ограничение данной программы, а не цитируемая универсальная граница формулы. Сравнение глубин ±1% — индикатор, не нормативный запас.

## Источники

- USACE HEC-RAS, Mixed Flow Regime Calculations: https://www.hec.usace.army.mil/confluence/rasdocs/ras1dtechref/6.0/overview-of-optional-capabilities/mixed-flow-regime-calculations
